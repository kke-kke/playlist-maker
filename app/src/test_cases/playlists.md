# Feature: Плейлисты

## Test Case ID: TC-007
## Title: Создание нового плейлиста

**Preconditions:**
- Пользователь находится на экране Плейлисты

### Steps:

1. Нажать "Создать плейлист"
2. Ввести название "Мои песни"
3. Сохранить

### Expected result:

- Новый плейлист "Мой песни" отображается в списке


## Test Case ID: TC-008
## Title: Удаление существующего плейлиста

**Preconditions:**
- Существующий плейлист есть в списке

### Steps:

1. Перейти на экран деталей плейлиста
2. Перейти в меню плейлиста
3. Выбрать пункт "Удалить плейлист"
4. Подтвердить удаление плейлиста

### Expected result:

- Плейлист удалён из списка
